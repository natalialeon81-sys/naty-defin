LA RAYA TODO — PORTAFOLIO

Archivos principales:
- index.html: estructura y contenido de la página.
- style.css: diseño, colores, grillas y adaptación a móviles.
- script.js: menú móvil, filtros de galería, ampliación de imágenes y cursor del león.
- assets/: logo, portada, ilustraciones y ejercicios de Imagen Escrita.

CÓMO USARLO EN TU PROYECTO
1. Haz una copia de seguridad de tu carpeta actual.
2. Copia index.html, style.css y script.js a la raíz de tu carpeta naty-defin.
3. Copia la carpeta assets incluida aquí a la raíz del proyecto. Si ya existe una carpeta assets, combina los archivos sin borrar tus recursos anteriores.
4. Abre index.html en Chrome para revisar el sitio.
5. Cuando esté listo, sube los cambios al repositorio GitHub naty-defin para que GitHub Pages publique la actualización.

PENDIENTE PARA UNA SIGUIENTE PASADA
- Añadir las URL reales de p5.js para los seis ejercicios cuando estén disponibles.
- Revisar o ajustar títulos de las ilustraciones si quieres usar sus nombres oficiales.
